# Repository-wide scope and nonclaims

This repository packages reproducibility evidence for the associated publication. Including additional reproducibility code does not enlarge the scientific claims.

## Scientific state

The source analyses are treated as fixed-version records for reproduction. The seven evidence dimensions used in the manuscript are a practical reporting framework derived from the audited cases, not a universal theory, validated scale, or cumulative score.

## H0DN scope

For a residual strictly in the support of a symmetric positive-semidefinite covariance, the target-dependent singular-Gaussian quadratic is invariant under an invertible row-coordinate transformation. The observed H0DN transformation result concerns a different setting: the design is nearly in covariance support, the rounded public data vector has an off-support component, and the Moore–Penrose quadratic is used as a projected loss. The measured non-invariance is tied to that off-support projected-loss extension.

The result does not establish that arbitrary singular-Gaussian inference is non-invariant. It does not define a preferred row representation, corrected covariance, corrected H0, pipeline error, or physical cause.

## Supernova scope

The compression identity is restricted to the fixed-covariance, one-intercept linear Gaussian model. Because the covariance is fixed, the compressed target estimate itself is sufficient for the one-intercept target likelihood; the stored scalar representation omits residual magnitude and pattern. It makes no sufficiency claim for added nuisance parameters, alternative mean models, covariance estimation, non-Gaussian likelihoods, or model selection.

The total residual statistic for the 277-row block is low under the nominal chi-square calibration, and a still lower residual component is localized to the specified 39-dimensional same-name contrast. The available evidence documents the statistic and its predefined robustness reruns but does not establish a complete prospective search history for all candidate residual subspaces and does not provide a multiplicity-adjusted confirmatory significance. The reported tail probabilities are therefore diagnostic calibrations for the specified statistic, not multiplicity-adjusted discovery probabilities.

## Explicit nonclaims

This repository does not establish:

- a corrected, preferred, or replacement H0;
- a revised Hubble-tension significance;
- a unique astrophysical, instrumental, calibration, survey, software, or institutional cause;
- erroneous or excessive Pantheon+ BBC corrections;
- an incorrect H0DN public value or covariance;
- a defective named pipeline, row-deletion rule, or covariance correction;
- statistical independence or dependence of the named supernova row pairs;
- an exact executed production history where only candidate inputs, filters, or configuration information were located;
- a solution to the Hubble tension or evidence for new physics; or
- external independent replication of implementations developed within this study.

Third-party raw data, posterior archives, HDF5 chains, large covariance arrays, and papers are not redistributed. Repository metadata describe only this software package and do not enlarge the scientific claims.
