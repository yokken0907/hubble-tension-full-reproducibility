# H0DN covariance-block influence and numerical-stability audit contract

Status: **frozen before block-influence results were generated**  
Freeze date: 2026-07-29 (UTC)  
Contract version: 0.1.0

## 1. Scope

This audit evaluates the numerical behavior and block influence of the public
Python implementation accompanying the H0 Distance Network (H0DN) paper. It is
a computational audit of the published baseline, not a new estimate of the
Hubble constant and not a physical explanation of the Hubble tension.

The upstream source is fixed to:

- repository: `https://github.com/StefCas789/H0DN`
- commit: `cc0a4b9f36e65470d514f254a3c5cffa463fbd94`
- default configuration: `h0_constrainer/configs/config.ini`
- expected upstream CLI result:
  `H0=73.4988+/-0.8088`, `chi2=117.5597`, `ndof=119`,
  `MB=-19.252+/-0.022`

The upstream repository has no repository-level license file at the frozen
commit, although its `pyproject.toml` refers to a missing `LICENSE` file.
Therefore, upstream code and data are not redistributed in this audit package.
They are acquired separately and verified by commit and SHA-256.

## 2. Questions fixed in advance

1. Does an untouched execution reproduce the public baseline?
2. What are the symmetry, definiteness, rank, nullity, spectrum, and condition
   diagnostics of the network covariance and normal matrices?
3. Is the solution stable under pre-specified pseudoinverse thresholds and
   mathematically equivalent representations?
4. Which explicitly encoded covariance components most affect the fitted
   `H0` and its reported uncertainty when ablated one at a time?
5. Which pre-specified equation blocks most affect the result when omitted one
   at a time, provided the remaining system is identifiable?
6. What numerical role is played by the full Pantheon+ Hubble-flow covariance,
   including its off-diagonal terms, before it is compressed into the single
   SN-Ia intercept equation used by the network?

## 3. Non-goals

- No covariance absent from the public implementation will be invented.
- No cross-method covariance will be estimated from overlap or intuition.
- No variant will be promoted as a corrected or preferred value of `H0`.
- No block shift will be interpreted as a causal or physical effect.
- No post-result regrouping will replace the blocks specified below.
- No statistical significance claim will be based on the exploratory
  leave-one-block-out table.

## 4. Baseline fidelity gate

The untouched public pipeline must satisfy all of the following:

| Quantity | Target | Acceptance |
| --- | ---: | ---: |
| equations | 255 | exact |
| parameters | 64 | exact |
| covariance rank | 183 | exact under upstream policy |
| `H0` | 73.4988 | absolute difference < `5e-5` |
| `sigma_H0` | 0.8088 | absolute difference < `5e-5` |
| chi-square | 117.5597 | absolute difference < `5e-5` |
| adjusted degrees of freedom | 119 | exact |
| `M_B` | -19.252 | absolute difference < `5e-4` |
| `sigma_M_B` | 0.022 | absolute difference < `5e-4` |

If this gate fails, all downstream outputs are labelled `NON_BASELINE` and may
be used only for debugging.

## 5. Matrix diagnostics

For the 255-by-255 network covariance `C`, report:

- dimensions, symmetry error, finite-value status, diagonal range;
- eigenvalue and singular-value extrema;
- positive, zero, and negative eigenvalue counts under each stated tolerance;
- upstream rank and nullity;
- full condition number and retained-subspace condition number;
- the Frobenius-norm closure error of the independently reconstructed
  covariance-component sum.

For `N = A.T @ pinv(C) @ A`, report the same applicable rank and spectrum
diagnostics. A negative eigenvalue is material if it is below
`-1e-12 * max(abs(eigenvalues))`. A decomposition closure residual is accepted
when it is at most `1e-12` relative Frobenius norm.

## 6. Solver policies fixed in advance

The upstream policy is:

```python
scipy.linalg.pinv(C, atol=1e-10, rtol=0.0)
```

and a direct inverse of the normal matrix.

The following sensitivity grid is fixed:

- absolute cutoff sweep, with `rtol=0`:
  `atol = 1e-14, 1e-13, ..., 1e-6`;
- relative cutoff sweep, with `atol=0`:
  `rtol = max(C.shape)*eps, 1e-14, 1e-12, 1e-10, 1e-8`;
- SciPy default `pinv` policy;
- the upstream policy after diagonal row standardization by
  `D = diag(C)^(-1/2)`, applying the exactly equivalent transformation
  `(A, y, C) -> (D A, D y, D C D)`;
- 32 simultaneous row/column permutations generated by NumPy
  `default_rng(20260729)`.

For equivalent-representation checks, numerical invariance is classified as
`PASS` if both `max(abs(delta_H0))` and `max(abs(delta_sigma_H0))` are below
`1e-6 km/s/Mpc`. All raw differences remain reported regardless of class.

## 7. Covariance components fixed in advance

The network covariance is reconstructed from the public code and captured input
metadata into these disjoint additive components:

1. host-measurement diagonal variances;
2. geometric-anchor rank-one components, one each for every encoded anchor;
3. MAS (method-anchor-source) rank-one components, one per encoded MAS;
4. HMS (host-method-source) off-diagonal components, one per repeated HMS;
5. group-equation diagonal variances;
6. SN-Ia calibrator diagonal variances;
7. SBF calibrator diagonal variances;
8. SN-Ia Hubble-flow-link variance;
9. SBF Hubble-flow-link variance;
10. megamaser diagonal variances, both individually and as a family.

Every exact component is ablated once by replacing `C` with `C - C_block`
while holding `A` and `y` fixed. Aggregate family ablations are also run.
HMS off-diagonal components are not positive semidefinite in isolation; their
ablations are explicitly labelled as algebraic diagnostics rather than
standalone uncertainty models.

## 8. Equation blocks fixed in advance

Leave-one-block-out removal is run for:

- host equations grouped by distance method;
- host equations grouped by geometric anchor;
- host equations grouped by source;
- host equations grouped by exact MAS;
- all group equations;
- all SN-Ia calibrator equations;
- all SBF calibrator equations;
- the SN-Ia Hubble-flow link;
- the SBF Hubble-flow link;
- every megamaser equation and all megamasers together.

Rows and matching covariance rows/columns are removed together. No parameter is
silently dropped. A result is numeric only if the retained covariance range
supports a full-rank normal matrix for all retained model parameters. Otherwise
the status is `HOLD_UNIDENTIFIED`, with ranks and dimensions reported.

## 9. Pantheon+ Hubble-flow covariance audit

The exact public Hubble-flow inputs and velocity prescription are reused.
Pre-specified cases are:

- full published covariance plus the public velocity-variance diagonal;
- diagonal-only published covariance plus the same velocity variance;
- the public covariance under the same cutoff and equivalent-representation
  diagnostics used above where applicable.

The output is the fitted intercept, intercept uncertainty, chi-square, rank and
matrix diagnostics. The diagonal-only case is a structural sensitivity test,
not an endorsed error model.

## 10. Reported influence quantities

For every successful ablation or omission:

- `H0`, `sigma_H0`, `log10(H0)`, and its variance;
- signed and absolute change from the untouched baseline;
- change expressed in units of the untouched `sigma_H0`;
- chi-square, covariance rank, normal-matrix rank, and retained dimensions.

No ranking is hidden: tables include all pre-specified blocks. Summary prose may
name the largest absolute shifts but must state that overlapping blocks are not
additive or independent.

## 11. Amendments and stop rules

Any change after this freeze must be appended to
`provenance/CONTRACT_AMENDMENTS.tsv` with timestamp, reason, and whether any
affected result had already been inspected. The original contract text is not
rewritten.

Execution stops with a machine-readable failure if:

- the upstream commit or file hashes do not match;
- covariance reconstruction does not close at the fixed tolerance;
- baseline fidelity fails;
- a non-finite matrix or result is encountered outside an explicitly reported
  unidentified leave-one-block-out case.
