# H0DN 共分散ブロック影響・数値安定性の独立監査

これは H0DN の公式成果物ではなく、H0DN 著者による提携・承認を受けた
ものでもない。人間の著者および最終責任者は Keiji Yoshimura であり、
AI 支援の役割と限界は `AI_ASSISTANCE_DISCLOSURE.md` に明記した。

## 統合結論

公開 H0 Distance Network（H0DN）の Python 基準計算を、固定コミット
`cc0a4b9f36e65470d514f254a3c5cffa463fbd94` と固定依存関係で再現した。
基準値は

\[
H_0 = 73.49875364 \pm 0.80880003\ 
\mathrm{km\,s^{-1}\,Mpc^{-1}}
\]

であり、公開出力、独立実装、Pantheon+ ハッブルフロー切片のすべてが一致
した。

この監査で最も重要な新しい結果は、255 本の方程式に対するランク 183 の
特異共分散を Moore–Penrose 逆行列で解く公開規約が、同値な非直交行
スケーリングに対して不変ではないことである。対角標準化だけで

\[
\Delta H_0=-0.05244542\ 
\mathrm{km\,s^{-1}\,Mpc^{-1}}
\]

となった。共分散ランクは 183 のままで、固定した逆行列カットオフ掃引でも
結果は変わらず、32 通りの行・列同時置換もすべて通過した。したがって、
これは単純なカットオフ境界や行順序の問題ではなく、特異行列に対する
Moore–Penrose 規約そのものの表現依存性である。

さらに、共分散の零空間 72 次元に対し \(P_0A\) は数値的にゼロだが、
\(\|P_0y\|_2=0.18874908\) mag であった。従って、共分散を文字どおりの
退化 Gaussian モデルとして読むと、どのパラメータ値もその厳密な台に
入らない。公開値は完全に再現可能だが、「冗長な方程式を捨てる」
Moore–Penrose 計算規約に依存しており、完全に指定された退化確率モデル
から表現不変に一意導出された値ではない。

これは公開 H0DN 値が誤りだという結論ではない。ましてハッブルテンション
を解消する修正値でもない。ただし、公開距離ネットワークの数値的な
トレーサビリティについて、論文・コードで明示すべき具体的な条件を
特定した。

## 監査の分離

結果を見た後に解析方針を遡及変更しないため、プロジェクト内部で結果閲覧
前に固定した契約により、三段階を分離した。

| 段階 | 契約 | 役割 |
| --- | --- | --- |
| 一次監査 | `AUDIT_CONTRACT.md` | 基準再現、全共分散成分、影響解析、数値安定性 |
| 事後診断 | `POSTHOC_DIAGNOSTIC_CONTRACT.md` ほか | 予期しなかった行標準化失敗の原因と位置 |
| 探索モデル | `EXPLORATORY_VARIANCE_COMPONENT_CONTRACT.md` | 明示的な全ランク生成モデルを一つだけ試す |

一次監査の結論を、後二段階の結果で上書きしていない。

## 基準系と行列診断

| 量 | 値 |
| --- | ---: |
| 方程式数 | 255 |
| パラメータ数 | 64 |
| 共分散ランク | 183 |
| 共分散零化次数 | 72 |
| \(\chi^2\) | 117.55968168 |
| 調整済み自由度 | 119 |
| \(M_B\) | \(-19.251823\pm0.022447\) mag |
| 正規方程式ランク | 64 |
| 保持部分空間の共分散条件数 | 約 53,274 |
| 正規行列の条件数 | 約 10,114 |

共分散を 60 個の素成分と 4 個の集約表示に独立再構成し、公開行列との
Frobenius 誤差は数値上ゼロだった。共分散には有意な負固有値はなく、
正規方程式は 64 パラメータすべてについて識別可能であった。

## 数値表現依存性の診断

対角行標準化は
\((A,y,C)\mapsto(DA,Dy,DCD)\) という厳密に同値な変換である。全ランク
共分散なら GLS 解は不変になる。しかし特異 \(C\) では一般に

\[
(DCD)^+ \ne D^{-1}C^+D^{-1}
\]

であり、公開系でも元座標へ戻した精度行列の相対 Frobenius 欠損は
`0.000380468374` だった。

| 検査 | 結果 |
| --- | --- |
| 絶対カットオフ \(10^{-14}\)～\(10^{-6}\) | 全てランク 183、同じ \(H_0\) |
| SciPy 既定相対カットオフ | ランク 183、同じ \(H_0\) |
| 32 通りの行・列同時置換 | 全て PASS、最大 \(|\Delta H_0|<4.8\times10^{-11}\) |
| 対角行標準化 | FAIL、\(\Delta H_0=-0.05244542\) |

零空間の厳密制約は
\(U_0^\mathsf{T}(Ax-y)=0\) である。公開系では
\(\|U_0^\mathsf{T}A\|_{\mathrm F}=1.88\times10^{-14}\) に対し、
\(\|U_0^\mathsf{T}y\|_2=0.18874908\) mag で、拡大行列のランクだけが
1 増える。固定許容差 \(10^{-10}\) では解なし
（`HOLD_INCONSISTENT_SUPPORT`）となる。

## 不整合の完全な位置同定

72 次元の零空間は、公開メタデータで選んだ R22 HST Cepheid の完全な
37 ホスト × 3 アンカー表における二元交互作用
\((37-1)(3-1)=72\) と一致した。111 セルを一つも除外せずに分解すると、
交互作用ベクトルと \(P_0y\) の最大差は
`1.07e-13` mag で閉じた。

| 指標 | 値 |
| --- | ---: |
| 全セル数 | 111 |
| 交互作用 L2 ノルム | 0.18874908 mag |
| 交互作用 RMS | 0.01791527 mag |
| 最大絶対セル | N3147 × N4258 |
| 最大絶対交互作用 | 0.09484685 mag |

絶対値の大きいセルは次の通りである。

| ホスト | アンカー | 交互作用 [mag] |
| --- | --- | ---: |
| N3147 | N4258 | +0.094847 |
| M1337 | N4258 | +0.079514 |
| N1015 | N4258 | +0.072180 |
| N3147 | MW | -0.047613 |
| N3147 | LMC | -0.047234 |
| M1337 | MW | -0.039946 |
| M1337 | LMC | -0.039568 |
| N1365 | N4258 | -0.039153 |

これは「どこで厳密加法台と公開 \(y\) が一致しないか」の同定である。
N3147、N4258、その他の個別測定が誤りだという証拠ではなく、丸め、
共分散構築、未表現の相関、校正構造、天体物理のどれが原因かも、この
分解だけでは判定できない。

## 明示的分散成分モデル

事後診断を受け、111 セルだけに追加の独立交互作用分散を置く

\[
C(\tau)=C_0+\tau^2R
\]

を、結果を見る前に別契約として固定した。外れ値除去、ホスト選別、
アンカー選別は行っていない。

| 推定・検査 | 結果 |
| --- | ---: |
| REML \(\tau\) | 0.02224362 mag |
| REML \(\Delta D=1\) 区間 | [0.02051154, 0.02423377] mag |
| REML \(\Delta D=3.841459\) 区間 | [0.01905208, 0.02643605] mag |
| ML \(\tau\) | 0.02219946 mag |
| 零空間モーメント \(\tau\) | 0.02224429 mag |
| REML 条件付き \(H_0\) | \(73.49432597\pm0.81186706\) |
| 公開基準からの \(\Delta H_0\) | -0.00442767 km/s/Mpc |
| REML 最適点の共分散ランク | 255 |

このモデルでは零モードが消え、元表現と対角標準化表現の REML
\(\tau\) 差は `2.50e-9` mag、\(H_0\) 差は `9.63e-10` まで縮まった。
つまり明示的な全ランク生成モデルにすれば、公開 Moore–Penrose 解で
見つかった表現曖昧性は解消できる。

一方、事前に固定した \(10^{-5}\le\tau\le0.3\) の全プロファイル点に
対する絶対 `1e-7` の検査は、\(\tau=10^{-5}\) で失敗した。その点は
最小値より \(3.56\times10^8\) 以上悪い極端な悪条件領域であり、95%
プロファイル区間内の最大差は `2.10e-11` だった。契約を緩めず、全体
状態を `PASS_WITH_FLAGGED_PROFILE_NUMERICS` として保持した。

この \(\tau\) モデルは一つの簡単な生成モデルにすぎず、独立セル分散が
物理的に正しいと確定したわけではない。それでも \(H_0\) の移動が
0.0044 km/s/Mpc と非常に小さいため、この特定の数値的問題を明示的に
修復しても、ハッブルテンション自体は事実上変わらない。

## 共分散成分除去による最大の代数的感度

以下は、加法的な共分散成分を一つ差し引いた後の、符号化された解法の挙動
である。主表には、除去後共分散が PSD で、ゼロ分散方向に対応する制約脱落
が検出されなかった `PSD_ALGEBRAIC_SENSITIVITY` だけを掲載する。これも
支持された代替誤差モデルではなく、原因帰属ではない。

| 除去した共分散成分 | \(\Delta H_0\) | 基準 \(\sigma\) 単位 | 解釈状態 |
| --- | ---: | ---: | --- |
| 全 MAS 成分 | +0.551468 | +0.682 | `PSD_ALGEBRAIC_SENSITIVITY` |
| LMC 幾何アンカー | +0.226583 | +0.280 | `PSD_ALGEBRAIC_SENSITIVITY` |
| 全 HMS 成分 | -0.206114 | -0.255 | `PSD_ALGEBRAIC_SENSITIVITY` |
| MAS: TRGB JWST × N4258 × A25 | +0.204228 | +0.253 | `PSD_ALGEBRAIC_SENSITIVITY` |
| MAS: Cepheid JWST × N4258 × SH0ES | +0.133308 | +0.165 | `PSD_ALGEBRAIC_SENSITIVITY` |

一部の成分除去はゼロ分散方向または不定値方向を生成する。その場合、
Moore–Penrose 逆行列は対応する制約を捨て得るため、結果を支持された
代替共分散モデル、または除去成分が誤りである証拠と解釈してはならない。
該当行は機械可読表に全て保持し、主表から分離した。

| 分離した代数診断 | \(\Delta H_0\) | 解釈状態 |
| --- | ---: | --- |
| SN Ia ハッブルフロー・リンク分散 | +0.867216 | `PSEUDOINVERSE_DISCARDED_CONSTRAINT` |
| SN Ia calibrator 対角分散 | +0.238373 | `PSEUDOINVERSE_DISCARDED_CONSTRAINT` |
| SBF ハッブルフロー・リンク分散 | -0.206124 | `PSEUDOINVERSE_DISCARDED_CONSTRAINT` |
| SBF calibrator 対角分散 | -0.188945 | `PSEUDOINVERSE_DISCARDED_CONSTRAINT` |
| ホスト測定対角分散 | -0.131039 | `INDEFINITE_ALGEBRAIC_DIAGNOSTIC` |

特に `sn1a_hubble_flow_link_variance` の除去では、共分散ランクが
183 から 182 へ低下し、方程式インデックス 248 の精度行が実質ゼロに
なった。得られた \(H_0\)、その誤差、全パラメータは、対応する
`sn1a_hubble_flow_link` 方程式を行・列ごと除去した結果と
\(10^{-9}\) の固定許容差内で一致した。従ってこれは「分散成分の科学的
除去」ではなく、制約脱落を伴う代数診断である。

ブロックはホストとパラメータを共有しているため、変化量を足し合わせては
ならない。不定値ケースも削除せず、科学的代替モデルではない
`INDEFINITE_ALGEBRAIC_DIAGNOSTIC` として保持した。

方程式行と対応する共分散行・列を同時に外す leave-one-block-out では、
最大の数値変化は SN Ia ハッブルフロー・リンク
（\(+0.867216\)）、SH0ES source 行
（\(-0.424086\)）、N4258 anchor 行
（\(-0.362929\)）、Cepheid JWST 行
（\(-0.334468\)）、CCHP source 行
（\(+0.316523\)）だった。これも各ブロックの誤りや因果性を意味しない。

## Pantheon+ ハッブルフロー共分散

277 天体の公開フル共分散から独立再構成した切片は

\[
\alpha=0.7163834211\pm0.0018926416
\]

で、公開コードと \(10^{-14}\) 未満で一致した。比較診断として非対角項を
ゼロにすると
\(\alpha=0.7158057374\pm0.0017057324\)、
ネットワーク全体では
\(H_0=73.41123022\pm0.79961785\)、
\(\Delta H_0=-0.08752342\) となる。

対角のみのケースは支持された代替誤差モデルではない。公開非対角共分散
への計算依存性を測ったものに限られる。

## 論文上の意味と次の実験

[H0DN 論文](https://doi.org/10.1051/0004-6361/202557993) は、255 方程式、
183 個の独立測定、72 個の冗長性を説明し、Moore–Penrose 逆行列を
線形従属方程式の除外と等価な手段として採用している。本監査は公開コード
の実装を正確に再現した上で、公開 \(y\) が特異共分散の台から外れる場合、
どの従属方向を捨てるかが非直交な表現変更に依存し得ることを具体的に示した。
これは論文の天体物理学的結論を反証するものではないが、数値等価性の主張
には「選んだ表現と零空間処理を固定する」または「全ランクの明示的生成
モデルを供給する」という条件が必要である。

次に科学的価値が高いのは次の順である。

1. 著者側の未丸め距離値、共分散生成手順、または潜在パラメータ記述を
   入手し、\(\|P_0y\|\) が丸め前にも残るか検証する。
2. 独立セル \(\tau\) だけでなく、ホスト相関、アンカー相関、低ランク
   校正項を含む生成モデル群を事前登録し、REML・予測検証で比較する。
3. 影響の大きい SN Ia ハッブルフロー・リンクと MAS 構造について、
   元の測定レベルから共分散を再生成し、圧縮前後の情報保存を検証する。
4. これらを固定した後にのみ、早期宇宙側との一貫したモデル比較へ進む。

公開コードは
[StefCas789/H0DN](https://github.com/StefCas789/H0DN)、
論文本文は
[Astronomy & Astrophysics](https://www.aanda.org/articles/aa/full_html/2026/04/aa57993-25/aa57993-25.html)
で確認できる。
