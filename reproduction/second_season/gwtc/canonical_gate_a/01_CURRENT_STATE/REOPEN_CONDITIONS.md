# Reopen conditions

Reopen Gate B only if official public material uniquely supplies:

1. `O4a_cosmology_results_paths_SR9.json` or an official equivalent registry;
2. the exact old-side posterior bytes behind `gw_dark_O4a`;
3. official checksums and version/record identity for those bytes;
4. an unambiguous mapping between that posterior and the 25.7% comparator;
5. sufficient documentation to reproduce the same arithmetic without inferred
   substitution.

Reopen Gate A only if:

- either headline posterior product receives a material official revision;
- the official release record or checksum changes;
- a documented error is found in the fixed percentile contract.

Do not reopen merely to extend the analysis into likelihood, MCMC, event-level,
causal-attribution, or other-probe integration.
