# Phase 0報告：SN Iaハッブルフロー圧縮の十分性

正式ステータス：**PASS_EXACT_SUFFICIENCY_FOR_FROZEN_LINEAR_MODEL**

境界マーカー：`FROZEN_MODEL_ONLY_NO_CORRECTED_H0_NO_TENSION_RESOLUTION`

## 結果

凍結したH0DNの1切片・固定共分散線形モデルに限れば、切片とその分散は、277天体ブロックがネットワークの推定パラメータへ渡す情報の厳密な十分統計量である。

独立Cholesky実装により、277行のPantheon+ハッブルフローデータから
\(a_B=0.716383421095462\)、
\(\sigma(a_B)=0.001892641639181\)
を再構成した。未改変上流実装は
\(a_B=0.716383421095462\)、
\(\sigma(a_B)=0.001892641639181\) である。

事前固定した11点の完全尤度対スカラー尤度の
\(\Delta\chi^2\) 恒等式における最大残差は `3.552714e-13`。
H0DNの1本のスカラー制約を277本の相関付き方程式に戻したとき、
全パラメータの最大差は
`7.815970e-14`、
パラメータ共分散要素の最大差は
`1.149254e-17`
だった。事前固定seedによる16置換での最大差は
`3.907985e-12` である。

未改変ベースラインは
\(H_0=73.498753643607\pm0.808800025338\)
km/s/Mpcのままである。非圧縮計算は同じモデルの等価表現であり、新しい値でも
補正値でもない。

## 1数値への圧縮で失われるもの

非圧縮ネットワークのchi-squareはスカラー版より
`206.760636437324` 大きく、その差は
ハッブルフロー単独の最小chi-square
`206.760636437324` と
`2.842171e-14` の範囲で一致した。
共分散rankと調整自由度はいずれも
`276` 増える。

したがって、1数値への圧縮は凍結モデルのネットワーク・パラメータ推定には十分だが、
残差診断、適合度評価、赤方偏移・サーベイ・速度場・母集団依存を持つ拡張モデルの
検定には十分ではない。

## 科学的境界

共分散のゼロ化・調整・再スケール・フィットは行っていない。制約も落としていない。
本監査は凍結モデルの物理的妥当性を検証せず、ハッブルテンションの有意度を推定せず、
補正H0を与えず、テンションが解消したとも主張しない。これは独立した計算監査であり、
H0DN共同研究の承認や査読ではない。
