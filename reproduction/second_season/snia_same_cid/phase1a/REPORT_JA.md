# H0DN SN Ia固定共分散・低残差χ²局在監査

正式ステータス：

`AUDIT_COMPLETE_LOW_CHI2_LOCALIZED_TO_DUPLICATE_NAME_CONTRASTS`

境界マーカー：

`FROZEN_MODEL_ONLY_NO_COVARIANCE_CORRECTION_NO_CORRECTED_H0_NO_TENSION_RESOLUTION`

## 統合結論

固定した公開H0 Distance Network（H0DN）のPantheon+ハッブルフロー
277行について、既知の低い残差chi-squareを、公開表のname文字列が完全一致
する行のコントラスト空間と、固有name間の空間へ分解した。

結果は

\[
\chi^2_{\rm total}=206.760636437324,\qquad \nu=276,
\]

\[
\chi^2_{\rm duplicate}=11.209315063603,\qquad \nu=39,
\]

\[
\chi^2_{\rm between}=195.551321373699,\qquad \nu=237
\]

であった。

重複nameコントラストは全自由度の14.1304%を占めるが、観測chi-squareへの
寄与は5.4214%だった。結果を見る前に固定した条件付きBeta検定では、
重複側の比率以下となる下側確率は
`9.368362232281232e-05`、両側確率は
`1.8736724464562464e-04` である。

プロジェクト内部で結果計算前にhash固定した1%両側基準により、全体の低いchi-squareは、
**同一天体nameの重複行コントラスト側へ不均衡に局在している**
と分類した。

## 何が新しく、何が既知だったか

Phase 0の時点ですでに、次は既知だった。

- 277行、238個の完全一致name群、30個の複数行name群（計69行）、
  重複nameコントラスト自由度39
- \(a_B=0.7163834210954622\)
- \(\sigma(a_B)=0.0018926416391806472\)
- 全体 \(\chi^2=206.7606364373241\)、自由度276

従って、固定既知Gaussian共分散を文字どおり仮定した全体の下側確率
`0.0006676284563444` は、本監査で結果閲覧前にプロジェクト内部で固定した
新規検定の結果ではない。

本監査で結果計算前にプロジェクト内部でhash固定した新しい検定は、
39自由度と237自由度への直交分解、および両者のchi-square比に対する
一回限りの条件付きBeta検定である。
契約、閾値、数値許容差、停止条件は
`provenance/CONTRACT_FREEZE.json` により結果閲覧前に固定した。
これは外部レジストリや第三者タイムスタンプを伴うものではなく、
プロジェクト内部の凍結契約である。結果確認後に行った「39」の語義修正は、
数値・閾値・分類・解釈境界を変更しない修正として、
`provenance/CONTRACT_AMENDMENTS.tsv` の `AMEND-001` に記録した。
凍結時の契約本文、決定設定、凍結記録は変更していない。

## 分解の定義

name列は、大小文字、句読点、表記を一切正規化せず、文字列の完全一致のみで
群分けした。外部天体resolverや手動統合は使っていない。

277行には

- 208個の1行name群
- 21個の2行name群
- 9個の3行name群

があり、合計238群となる。2行群は各1、3行群は各2のコントラスト自由度を
持つため、重複nameコントラスト空間は
\(21+2\times9=39\) 自由度である。

一切片モデルを \(X_0=\mathbf 1\)、name別切片モデルを238列の
incidence行列 \(X_1=Z\) とした。固定共分散をCholesky白色化し、二つの
入れ子射影から

\[
\chi^2_{276}
=\chi^2_{{\rm duplicate},39}
+\chi^2_{{\rm between},237}
\]

を得た。

## 条件付き統計

固定され、既知で、正しいGaussian共分散という限定条件の下では、

\[
\chi^2_{\rm duplicate}\sim\chi^2_{39},\qquad
\chi^2_{\rm between}\sim\chi^2_{237}
\]

は独立であり、

\[
R=\frac{\chi^2_{\rm duplicate}}{\chi^2_{\rm total}}
\sim {\rm Beta}(39/2,237/2)
\]

となる。

| 量 | 値 |
| --- | ---: |
| 観測 \(R\) | 0.054213970593 |
| 自由度比 \(39/276\) | 0.141304347826 |
| Beta下側確率 | \(9.3683622\times10^{-5}\) |
| Beta上側確率 | 0.999906316378 |
| 両側確率 | \(1.8736724\times10^{-4}\) |

周辺下側確率は、重複name成分で
`3.679524587663957e-06`、name間成分で
`0.022934426680855293` だった。これらは記述的な副次量であり、主分類を
変更する追加検定には用いていない。

## 科学的解釈の境界

この結果から直接言えるのは、固定モデルの低残差chi-squareが、
name完全一致で定義した重複行の差分方向へ不均衡に集中しているという
ことだけである。

この監査は次を確立しない。

- 重複行が誤りである
- 重複行が統計的に独立または同一測定である
- 公開共分散が過大評価されている
- 特定のSN、サーベイ、較正、速度補正が原因である
- 複数行name群の行を削除または平均化すべきである
- \(a_B\)、\(M_B\)、\(H_0\)を修正すべきである
- ハッブルテンションの有意度が低下した

特に、公開nameの一致は物理的同一性やsurvey provenanceを完全に保証する
ものではない。全共分散は複数行間の相関を既に含むため、重複行を単純に
落とす操作は支持されない。

## 次に許される問い

次段階として最も情報利得が高いのは、30個の複数行name群、計69行を対象に、
各行がどのsurvey・light-curve fit・較正経路・共分散成分から生成されたかを
公開sourceだけで追跡できるかを調べる、別契約のprovenance監査である。

その監査では、結果を見る前に次を固定する必要がある。

- 行からPantheon+原資料への一意なmapping
- 同一name内の測定関係の分類
- 対応する部分共分散の生成根拠
- source不足時のHOLD条件

本Phase 1Aはその追跡、個別nameランキング、共分散変更を実行せず、ここで
停止する。

これはKeiji Yoshimuraによる独立監査であり、H0DNまたはPantheon+
collaborationの承認、公式検証、査読ではない。
