# Phase 1C 報告：同一CIDコントラストの共分散校正監査

## 結果

来歴・入力・共分散系譜・数値検証の必須ゲートはすべて通過した。正式な
status は
`AUDIT_COMPLETE_CONTRAST_COVARIANCE_CALIBRATION_DIAGNOSTIC`
である。
限定修正と終結監査後の判定は `ACCEPT_COMPLETE_WITH_SCOPE` である。

事前固定した感度分類は次のとおり。

`LOW_FLAG_PERSISTS_THROUGH_STATONLY`

39自由度に対する結果は以下である。

| 事前固定した基準 | chi-square | 下側参照確率 | q / df |
| --- | ---: | ---: | ---: |
| Phase 1A full | 11.209315063602716 | 3.6795246e-06 | 0.2874183 |
| 行ごとの速度項を除いたSTAT+SYS | 14.734235950587198 | 1.4711329e-04 | 0.3778009 |
| STATONLY | 16.233447508593247 | 4.8568326e-04 | 0.4162422 |

3つとも、事前固定した強い低分散判定 `p < 0.001` を満たす。ただし、
これは各共分散を固定・既知と仮定したガウスモデルに対する参照確率であり、
多重性調整済みの新発見検定ではない。
強い低分散という記述ラベルの閾値は `p < 0.001`、順序付き感度フラグの
閾値は `p < 0.01` であり、両者は別である。主解析の3基準はいずれも
両方を満たす。

Phase 1Aの条件付きBeta確率 `9.3683622e-05` と、Phase 1Cの周辺
\(\chi^2_{39}\) 下側確率 `3.6795246e-06` は、同じ確率の別実装ではない。
異なる参照問題への答えなので、数値が異なることは不整合ではない。

## 共分散を替えたとき何が変わったか

H0DNの行ごとの240 km/s速度分散項を外すと、chi-squareは11.21から
14.73へ上昇する。39次元コントラスト空間で、Phase 1A full共分散を
STAT+SYSのみの共分散と比べた一般化固有値は1.044から1.550、幾何平均は
1.326である。

STAT+SYSをSTATONLYへ替えると、chi-squareはさらに16.23へ上昇する。
STAT+SYSをSTATONLYと比べた一般化固有値は1.0003から1.9015、幾何平均は
1.0969である。

したがって両成分は数値に影響する。しかし、どちらの遷移でも低分散
フラグは消えない。

対角成分だけを残した補助診断では、STAT+SYSが9.1554、STATONLYが
9.9372である。この観測ベクトルでは、公開off-diagonal構造を戻すと
chi-squareは下がるのではなく上がる。これら2つは構造診断に限定され、
主分類には使っていない。

また、凍結表では同一CIDの各行について宇宙論モデル項が完全に同一であり、
そのコントラスト最大値は厳密に0だった。39モードの情報は、同一CID内の
等級差だけで担われている。

## 凍結済み事後精度・非対称性診断

主結果の判明後、限定的な査読指示により2つの補助診断を追加した。新しい
値を読み込み・計算する前に、内部result-blind契約をSHA-256
`050272af008385d0f4d5e247d1a81a432411115f972bc6a52562a580d8f3d5b4`
で凍結した。これは外部事前登録ではなく、主解析の改変でもない。

Phase 1Bの対応、群、39行Helmert基底、3つの共分散基準を同一に保ち、
H0DNの印字 `m_b` だけを公式高精度 `m_b_corr` に替えた結果は次のとおり。

| 基準 | 印字値 q | 高精度値 q | 高精度 − 印字 |
| --- | ---: | ---: | ---: |
| Phase 1A full | 11.209315063602716 | 11.181959816277521 | -0.027355247325195 |
| 速度項なしSTAT+SYS | 14.734235950587198 | 14.694714732492480 | -0.039521218094718 |
| STATONLY | 16.233447508593247 | 16.192911494208520 | -0.040536014384728 |

高精度値の下側確率は順に `3.5535125e-06`、`1.4219325e-04`、
`4.7133432e-04` である。固定39成分コントラストの最大絶対差は
`9.899494936649322e-05`、L2差は `2.879814808859486e-04` だった。

raw mapped STAT+SYS と STATONLY の277×277部分行列は、どちらも
非対称off-diagonal pairが0だった。各1701×1701全行列には778個の
有向非対称要素があり、最大転置差は `3.0000000000038676e-08` だが、
すべて選択範囲外にある。したがって実データでは、凍結済みの
upper/lower/symmetric-average感度分岐は正しく発火しなかった。その計算式は
非対称小行列fixtureで検証している。

## 科学的に言える範囲

今回得られたのは、否定的だが有用な絞り込みである。

- H0DNの行別速度分散項を除いても低分散フラグは残った。
- 公開systematic covariance成分を除いても低分散フラグは残った。
- 公開STATONLY共分散を基準にしても低分散は残る。

次の科学的焦点は、測定値の構成と依存性である。同じCIDを持つ異survey行が
コントラストモデルで想定するほど独立か、誤差の導出過程を共有していないか、
選択・圧縮処理が追加の一致を生んでいないか、という問いに進む根拠が得られた。

ただし本監査は、それらの可能性を区別していない。特に `q/df < 1` だけを
根拠に、すべての誤差を `sqrt(q/df)` 倍すべきだとは言えない。記録した
scale区間は仮想的な一様スケール族の診断であり、修正提案ではない。

## 検証

- H0DN実装4ファイルを含む、2つの固定commitのsource lock 13/13を確認。
- Phase 1AとPhase 1Bの正規ZIPについて、ファイル名、SHA-256、sidecar、
  CRCを実体照合。
- Phase 1Bの277行対応は全行で一意なtargetを持ち、両表と一致。
- 30群・69行・39自由度で、全群が異survey。
- 公式STAT+SYS部分行列とH0DNは76,729/76,729要素でfloat64完全一致。
- 5つの射影共分散はすべて正定値。
- 既知のPhase 1A値との差は `3.6e-14`。
- Cholesky法と固有分解法の差は最大 `1.5e-14`。
- 別構成のnull-space基底との差は最大 `1.5e-13`。
- 32回の直交座標変換をすべて通過。
- 独立検証器は5基準と分類を再現。
- 単体・敵対的テスト33/33を通過。
- clean copyで主解析・事後診断の22/22ファイルがbyte単位で一致。
- `verify_results.py` はmanifest対象ファイルを一切変更しない。

## 契約01のschema HOLD

契約01では、公式共分散の転置差が当初上限 `1e-12` を超えたため、新しい
chi-squareを計算する前に停止した。最大差は
`3.0000000000038676e-08` だった。旧契約・設定・freezeを保存し、schema
診断を開示した上で、すでに宣言していた `(C+C.T)/2` 変換を維持し、
許容上限のみ `5e-8` とした契約02を科学結果の計算前に再freezeした。

今回の修正では、契約02のSOURCE_LOCKを2,255 bytesの完全一致する凍結
prefixとして保存し、旧upstream dependency JSONもbyte一致のsnapshotで
保存した。追加分は改訂台帳と別の事後診断契約に記録している。

## 非主張

本結果は、次のことを主張しない。

- 特定の天体、survey、survey pairが異常である。
- 公開された統計的不確かさを全体として読み替えるべきである。
- 共分散の一律縮小や行の統合を行うべきである。
- 修正済み \(a_B\)、\(M_B\)、\(H_0\) が得られた。
