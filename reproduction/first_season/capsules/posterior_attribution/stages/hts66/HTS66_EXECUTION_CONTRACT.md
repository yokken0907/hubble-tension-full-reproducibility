# HTS66 execution contract

## Stage
`HTS66_ATTRIBUTION_INVARIANT_CORE_SYNTHESIS_AND_BRANCH_CLOSEOUT`

## Question
Across the exact HTS59–65 result archives, which quantities are cross-stage invariants, which
remain convention-dependent, and is any further coordinate/eigenmode/coalition attribution
of the same released endpoints justified?

## Frozen sources
The exact HTS59, HTS60, HTS61, HTS62, HTS63, HTS64 and HTS65 result ZIPs, each selected by
predeclared outer SHA256 and verified by ZIP CRC, internal SHA256 manifest and canonical
classification.

## Operations
- verify all seven result archives
- require identical 28 directed edge/burn keys
- cross-check conditional four-dimensional distances through HTS59–65
- cross-check HTS62 fixed-block totals through HTS63, HTS64 and the HTS65 canonical partition
- record HTS61 eigengap-limited clusters
- record HTS64 basis sensitivity and HTS65 partition sensitivity
- produce a machine-readable invariant hierarchy
- formally close further attribution decomposition of the same endpoint set

## Gates
- seven exact source ZIPs and expected classifications
- all internal manifests and CRCs PASS
- all directed key sets identical
- maximum conditional-distance cross-stage discrepancy <= 1e-10
- maximum fixed-block cross-stage discrepancy <= 1e-10
- complete 14-edge primary sensitivity accounting
- independent reconstruction PASS

## Closeout boundary
Further coordinate, eigenmode or coalition decomposition is not selected after HTS66.
Reopening requires an externally justified physical parameterization, an exact component
posterior edge, or a new independent data product.
