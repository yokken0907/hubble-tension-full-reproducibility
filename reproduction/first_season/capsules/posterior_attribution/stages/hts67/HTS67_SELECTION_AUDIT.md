# HTS67 selection audit

## Selected
A single symmetric/pooled metric robustness audit.

## Why selected
The frozen HTS62 block bookkeeping can reverse between forward and reverse directions because each direction uses a different source posterior covariance. This is an explicit unresolved robustness question rather than a search for a preferred attribution.

## Rejected alternatives
- more coordinate rotations
- additional eigenmode labels
- further Shapley, Owen or coalition partitions
- new physical parameter combinations chosen after inspecting results
- likelihood-component causal claims
- new cosmological models

These alternatives are outside the HTS66 closeout boundary or require new external justification.
