# Repository Content Policy

## Included
Only files needed to reproduce, verify, or trace manuscript/supplement claims are included:
project-created code, contracts, compact result tables, source registries, claim crosswalks, exact fixtures, selected historical replay intermediates, and the exact manuscript PDFs.

## Excluded
The complete project working tree, caches, duplicated review ZIPs, large third-party source payloads, and non-scientific work logs are excluded.

## Historical material
Historical files are retained only when a current reproduction path depends on them (for example HTS59-67 portable/replay lineage). Their presence does not make them current scientific authority.

## Authority
The four frozen master identities remain authoritative scientific records. This repository is a reproduction layer constructed from those records and does not rewrite their closure.
