# Repository Content Policy

## Included

Only files needed to reproduce, verify, or trace the scientific claims are included: project-created code, numerical contracts, compact result tables, source registries, claim crosswalks, exact fixtures, selected historical reproducibility intermediates, and fixed evidence records.

## Excluded

The repository excludes manuscript and supplement PDFs, the complete project working tree, caches, duplicated review/transport archives, large third-party source payloads, papers, and nonessential work-log material.

## Historical material

Historical records are retained only when a current reproduction or evidence-tracing path depends on them. They may contain the original project status vocabulary, historical filenames, or machine-specific execution paths. Their presence preserves provenance and does not make those strings part of the current public interface or reproduction requirements. See `docs/HISTORICAL_RECORDS_NOTE.md`.

## Authority

The four version-locked archival package identities listed in `docs/PROJECT_SOURCE_SELECTION_REPORT.md` remain the scientific source records. This repository is a reproduction layer constructed from those records; it does not rewrite their historical contents.
